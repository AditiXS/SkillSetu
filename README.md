# SkillSetu 🚀

SkillSetu is a comprehensive peer-to-peer learning platform designed to empower users to share skills, document their learning journeys, and connect through real-time collaboration.

## ✨ Key Features

### 👨‍💻 Real-Time Peer Collaboration
- **Video Chat & Messaging**: Seamless WebRTC-powered video conferencing and real-time socket-based messaging for interactive learning sessions.
- **Session Scheduling**: Intelligent scheduling system with timezone-aware validation to prevent booking past dates.

### 🏆 Social Learning & Community
- **The Journey Feed**: A global social wall where users share milestones, project updates, and lesson achievements with image support.
- **Interactive Feed**: "Congratulate" peers on their progress with a real-time celebration system.
- **Skill Communities**: Join or create specialized groups dedicated to specific technologies and skills.
- **Leader Authority**: Group creators have full administrative control to manage and moderate their communities.

### 👤 Profile & Portfolio
- **Verified Achievements**: Showcase your learning milestones and journey history.
- **Robust Validation**: Professional profile management with validated fields for bios, socials, and contact info.
- **Credits & Wallet**: Integrated system for managing session credits and transactions.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, Lucide Icons, GSAP (Animations)
- **Backend**: Node.js, Express, Socket.io
- **Database**: MySQL with Sequelize ORM
- **Auth**: JWT & Firebase Google Authentication support

## 🚀 Deployment Ready
The project is configured for cloud deployment (e.g., Railway, Render) with:
- `DATABASE_URL` support for cloud SQL.
- Dynamic Environment Variables for API and Frontend routing.
- Production-hardened CORS and Security settings.
